# Hospital ER Dashboard — Power BI

An interactive hospital dashboard built with **Power BI**, following a guided project tutorial.

### Tools

* Power BI
* Power Query
* DAX

### Key Features

* Hospital performance overview
* Patient and admission analysis
* Department and medical service insights
* Interactive filters and visualizations
